The figures are kept in the private GitHub repository dezzaCodes/flower-ledger, so only you can see them. Each device needs a GitHub token once:

  1. Open New fine-grained token.
  2. Under Repository access, choose Only select repositories and pick flower-ledger.
  3. Under Permissions → Repository permissions, set Contents to Read and write.
  4. Generate the token and paste it here.
